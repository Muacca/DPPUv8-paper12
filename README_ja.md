# 異方的コンパクト宇宙の Dirac 場の断熱的端点偏極、Fock 実装可能性と励起エネルギー

Muacca · DPPUv8 Paper 12 · **v1** · 初版 2026-11-22

## 要旨

厳密な二軸三次元球面宇宙の二つの丸い端点の間で、質量ゼロの外部 Dirac 場を伝播させる。瞬時の端点分解では、正負の混合を表す作用素が Hilbert–Schmidt 条件を満たさない。一次の断熱的端点偏極を用いると粒子数と正孔数の期待値はともに正で有限になるが、それぞれの物理的な端点エネルギーの絶対値を占有数で重み付けした和は、殻の打切りとともに対数発散する。二次ではこのエネルギーも有限になる。二準位系に対する一様評価により磁気量子数の格子の端まで収束を示し、内側の帯域で離散的な位相を評価して対数発散の下界を得る。551組の磁気モード対に対する区間積分と紫外尾部の解析的評価を合わせ、二つの次数での有限な総数と二次のエネルギーを上下から抑える。膨張するコンパクト Nil 幾何の二つの時間区間については、独立な二指標の総和により、瞬時偏極の実装が不可能であり、一次では和が収束することを示す。これらの観測量は、指定した各履歴上の外部場および端点射影を用いて定義したものである。
